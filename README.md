# Completed Assignments

## Week 2 — Assignment 1: CRUD Operations API

**Folder:** `CRUD-Operations`

A RESTful Task Management API built using **FastAPI** that demonstrates complete CRUD (Create, Read, Update, Delete) operations using an **in-memory Python list**.

### Features

- Create new tasks
- Read all tasks
- Read a single task by ID
- Update existing tasks
- Delete tasks
- Request validation using Pydantic
- Proper HTTP status codes
- Interactive Swagger UI documentation
- RESTful API design

### Technologies Used

- Python
- FastAPI
- Pydantic
- Uvicorn
- Swagger UI (OpenAPI)

For complete documentation, see:

**`CRUD-Operations/README.md`**

## Week 3 — Assignment 1: SQLite CRUD API

**Folder:** `SQLite-CRUD-Operations`

This project extends the previous CRUD API by replacing the in-memory task list with a **SQLite database**. The API endpoints remain unchanged while the data is now stored permanently.

### Features

- Persistent task storage using SQLite
- Automatic database creation
- Automatic table creation
- Automatic insertion of sample tasks
- Create, Read, Update and Delete operations using SQL
- Parameterized SQL queries
- Data persists after server restarts
- Interactive Swagger UI documentation

### Technologies Used

- Python
- FastAPI
- SQLite
- sqlite3
- Pydantic
- Uvicorn

For complete documentation, see:

**`SQLite-CRUD-Operations/README.md`**
