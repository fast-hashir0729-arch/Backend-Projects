## Assignments

### Week 2 — CRUD Operations API

**Folder:** `CRUD-Operations`

A RESTful Task Management API built using **FastAPI** that demonstrates complete CRUD (Create, Read, Update, Delete) functionality using in-memory storage.

### Features

- Create new tasks
- Read all tasks
- Read a single task by ID
- Update existing tasks
- Delete tasks
- Input validation
- Proper HTTP status codes
- Interactive Swagger UI documentation
- RESTful API design

### Technologies Used

- Python 3
- FastAPI
- Pydantic
- Uvicorn
- Swagger UI (OpenAPI)

For detailed setup instructions and API documentation, see:

**`CRUD-Operations/README.md`**
